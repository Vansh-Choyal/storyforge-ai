# Examples

This directory contains sample books generated with StoryForge AI.

## Included Samples

### The Celestial Codex: Secrets Beyond the Stars.pdf

**Prompt**

> Generate me a story about an astronaut who finds a huge library on an asteroid while space-mining.

### Turbo Treasures in the Lands of Autovia.pdf

**Prompt**

> A short 3-chapter story about cars. Cars are the main characters. No humans involved. The main car is Veltrix Phantom GT.

## Purpose

These examples demonstrate how StoryForge AI can transform a simple prompt into a complete, multi-chapter PDF book.

You can use the generated PDFs to:

- Verify PDF formatting
- Review story quality and consistency
- Evaluate chapter structure and pacing
- Inspect the overall output generated by the workflow
